One sentence that could have replaced an entire pointless meeting.

## Entry

> We already decided this in the elevator — this meeting is just the group photo.

## How it works

`main.py` deterministically writes the entry to `/output/entry.txt` and
gates it first: UTF-8, 1–200 characters, a single line, not only
whitespace, and exactly one sentence.

```sh
python3 main.py
```
